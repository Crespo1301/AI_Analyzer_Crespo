# Week 01 Prompt Workspace

Use this folder when the 2026 NFL Week 1 slate is ready.

Recommended files:

- `games.md` for the selected schedule and market lines
- one filled prompt file per game and template
- `runs.md` to track which model received which prompt

Do not rely on chat history alone. Save the filled prompts and raw model outputs
so the response can be graded later.
