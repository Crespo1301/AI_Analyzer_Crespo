# AGENTS.md

Guidance for Codex and Claude when working in this repo.

## Project Role

AI Analyzer is a CSolutions public credibility project. The original version was
a senior-year AI comparison experiment around NFL betting prompts. The next
version is a larger, cleaner, season-long tracking system for comparing model
predictions, prompt quality, bet types, and reasoning quality during the NFL
regular season.

Do not frame this as active academic research. The public angle is: "Ahead of
the next NFL season, I am revisiting an old AI research project and documenting
what still holds up."

## Source Of Truth

- `assets/nfl-data.js` is the current public data source for games, bets, scores,
  correction overlays, and computed summaries.
- `Sports_Pages/*.html` is generated by `scripts/build-game-pages.js`. Do not
  hand-edit generated game pages.
- `Docs/GRADING ANALYSIS/` contains older exported reports. Treat those as
  historical evidence, not the current truth when they disagree with
  `assets/nfl-data.js`.
- `Docs/2026/` and `Prompts/2026/` define the upcoming season workflow.
- `Docs/Responses/2026/` is where raw model response files should be stored by
  week once the season starts.

Use `/home/cresp3/scripts/visual-check.sh` for layout, mobile, or screenshot

## Betting Data Rules

- Always save raw model responses before extracting bets.
- Never reward wordiness by itself. Score reasoning only when it names a factor
  that actually mattered to the result.
- Every bet must have model, week, prompt id, game, market type, line when known,
  stake, outcome, return, profit/loss, and grading notes.
- Props must be checked against the final box score stat line.
- Direct ESPN box-score URLs are required. Generic week scoreboard links are not
  enough.
- If a recommendation is too vague to audit later, flag it as low-confidence
  evidence instead of pretending it is precise.
