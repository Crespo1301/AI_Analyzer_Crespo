# 2026 Data Workspace

Use this folder for season intake files before they are added to
`assets/nfl-data.js`.

Recommended files:

- `week-XX-research.md`
- `week-XX-lines.csv`
- `week-XX-bets.csv`
- `week-XX-boxscore-links.md`

Rules:

- Keep raw intake separate from the public site data until verified.
- Prefer direct ESPN box-score URLs.
- Preserve the original model wording somewhere before simplifying it into a
  structured bet row.
